# 与广告部门自动审核项目的方向对比(GAP 分析)

> 记录日期:2026-07-12 · 学习广告部门自动审核项目后的补充思考

## 观察到的 GAP

学习了广告部门的自动审核项目后,发现一个方向上的 GAP:

- **电商 CQC(我们)的路线:助审优先**。主要做的是把机器相关的信息(违规点、违规码、规则引用等)暴露给人工审核,让审核员参考这些信息做出判断;其次才是完全利用机器直接把判断结果呈现出来、替代人工思考。
- **广告部门的路线:替代优先**。优先做的是替代人工选标签——直接把结果给到人工审核;其次才是做助审,把相关的违规信息、违规点作为数据和证据参考给到人工。

两个部门做的东西方向刚好相反,同时也是互补的。

## 为什么会形成相反的路线

这个差异不是偶然,主要由**标签空间结构**和**判断链长度**决定:

- **广告审核的标签空间更标准化、可枚举**:投放物料类型有限,违规类型收敛,模型直接预测标签的可行性高,替代人工选标签是一个边界清晰的分类问题。
- **电商治理的判断链更长**:类目 → 规则细则 → 商品的哪个要素违规 → 固证。标签背后还挂着证据要求(标题片段、第几张图、资质字段),直接替代的门槛天然更高。

所以电商侧「助审优先」不是保守,而是问题结构不同。

## 两条路线的隐含要求

| 维度 | 替代优先(广告) | 助审优先(电商) |
| :--- | :--- | :--- |
| 核心能力要求 | 从第一天就必须做**置信度校准**(什么时候敢让机器拍板) | 信息抽取与证据组织(违规点引用、固证) |
| 主要风险 | 高置信误判直接造成错误处置 | 停留在「透传信息但不为结果负责」的舒适区;低精确率透传造成锚定效应 |
| 北极星指标 | 自动化率 / 在精确率阈值下的覆盖率 | 单 case 人审时长下降、助审覆盖量 |
| 对数据的要求 | 高质量标签(结果导向) | 高质量证据链(过程导向) |

值得警惕的一点:助审路线因为「不直接为结果负责」,容易在精确率很低(如 ~11%)时也能上线运行——广告路线的纪律值得借鉴,**给每条透传信息都算置信度,哪怕暂时不用来替代**。

## 互补与协作空间

两边其实在同一张「人机协同光谱」上从相反两端往中间走:

- 电商侧规划中的**统一治理检测模型**(多标签风险分类器 + 置信度分层路由),本质上就是广告部门正在做的「替代人工选标签」;
- 反过来,电商侧已经建立的**固证 / 违规点引用能力**,正是广告部门二期要做的助审;
- 可共享的资产:评估集构建方法(双人标注 + 仲裁 + Kappa)、置信度校准方案、质检闭环设计、按「队列 × 体裁」灰度铺开的运营打法。

各自少走一半的路。

## 对电商侧的启示

不必在「助审」和「替代」之间二选一,**按置信度分层就是两条路线的合流点**:

| 置信度 | 策略 | 对应路线 |
| :--- | :--- | :--- |
| 高置信 | 直接出标签 / 驳回 | 替代(广告的一期) |
| 中置信 | 透传违规点 + 证据给人审 | 助审(电商的一期) |
| 低置信 | 纯人审,不透传低质信息 | 避免锚定效应 |

落地建议:先在某个**标签收敛、规则明确的队列**(结构上最接近广告场景的,比如某个高频违规码 × 静态商品)试点「高置信直接出标签」,用试点数据反哺检测模型的置信度校准能力,再逐步扩大替代段的占比。
